Tenant Access

Single sign-on for small companies that run their own tools, like Grafana and Outline. One login, and one place to see who has access.

  • Solo project
  • FastAPI, PostgreSQL, React
  • Render, Neon, Cloudflare
Open the live demo Source on GitHub

No account needed. The demo is a read-only sample company, and the free server can take 30 seconds to wake up.

What it does

  • Sign-in with Google or Microsoft, matched to the company by verified email domain
  • Its own OpenID Connect provider, so Grafana and Outline sign in through it
  • Access rules per app, an audit log, CSV export and signed webhooks
  • Partner mode for IT firms that look after several companies

What I learned

Test with the same database role as production. A security guarantee that only holds in CI isn't one.

The hard parts

Isolation in the database

Every tenant table has forced row-level security, so a query that forgets its tenant filter gets nothing back. In production it was silently off, because Neon's owner role bypasses RLS. Now the app runs as a restricted role and refuses to start if it could bypass the policies.

ALTER TABLE users FORCE ROW LEVEL SECURITY;

CREATE POLICY tenant_isolation ON users USING (
  tenant_id = current_setting('app.tenant_id')::uuid
);

Closing nOAuth

A Microsoft work email only counts when its directory has verified the domain, and accounts are never linked by email alone.

A demo nobody can break

One server-side rule refuses every write from a demo session. Its app secrets were thrown away, and visitor IPs are never stored.

Webhooks that stay outside

Signed and retried, and refused for private or loopback addresses, so they can't probe the server's own network.
